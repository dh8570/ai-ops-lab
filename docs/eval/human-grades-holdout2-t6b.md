# 사람 채점 (새 보류 s12~s15) (A1-T6b 후속)

`docs/eval/scoreboard-20261105T073516Z.md` 표 ⑮의 warm 1번 호출 12개를 PM이 사람 기준으로 채점. 정확성·유용성 0~2.

## 평균
- 정확성: all_v1 0.75, all_v2 1.75, all_v3 1.25
- 유용성: all_v1 1.25, all_v2 1.25, all_v3 1.00
- 자리표시 복사: all_v2 3/4칸, 나머지 0

## 관찰
- v3는 사전 채택 기준 ①(새 보류 사람 정확성 >= v2)도 실패했다(1.25 대 1.75).
- 원인 칸을 1개로 풀어 주자 모델은 정직해지지 않고 한 원인을 단정했다(s13). 오염은 확인 항목(없는 컨테이너 이름, 틀린 경로)으로 옮겨 갔다.
- s13 all_v2는 자동 판정은 통과(warm 3/3)지만 사람은 1/1이다. "알 수 없음" 면제가 통과율을 부풀린다는 의심이 이 칸에서 확인됐다.
- 진짜 기권("알 수 없음: 실제 이유")은 어느 조건에서도 나오지 않았다.
- 표본이 작다(시나리오마다 1회). 방향만 믿는다.
